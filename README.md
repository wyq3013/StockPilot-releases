# StockPilot 版本发布

StockPilot 的安装包、版本说明、更新清单及文件校验信息通过本仓库的 [Releases](https://github.com/wyq3013/StockPilot-releases/releases) 发布。

## 下载与安装

1. 在 Releases 中选择适合自己系统和芯片架构的版本，并阅读该版本说明。
2. 下载 DMG 与对应的 SHA-256 校验文件，核对文件完整性。
3. 更新前先完成数据备份并退出 StockPilot。
4. 打开 DMG，将 `StockPilot.app` 拖到 Applications，替换同名应用；完成后推出磁盘，再从“应用程序”打开。

应用内检查、下载与安装能力以对应版本的发行说明为准。出现系统安全提示时，保留提示并反馈，不关闭系统安全机制。

## 发布内容

- Mac 安装包（DMG）。
- 版本说明与安装使用说明。
- SHA-256 校验文件。
- 更新清单及其公开验证信息（按版本提供）。

开发源码在独立的私密仓库维护。本仓库不上传源码 ZIP、个人交易记录、原始 TXT、数据库、备份、凭据或私钥。公开安装包可由任何人下载，其中的部分程序代码可能被提取查看。

## 反馈

反馈时请提供应用版本、系统版本、复现步骤与错误提示。截图请遮盖个人信息；不要提交原始 TXT、数据库、备份文件、口令或密钥。

StockPilot 用于交易记录、复盘分析与风险提示，不构成投资建议。
